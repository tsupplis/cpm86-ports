# Historical licensing evidence

The supplied source identifies RESOURCE by Ward Christensen, the 8086
translation by Larry Etienne, and added features by W. Earnest. It contains
`Copyright 1980` following its sign-on text. These notices are preserved.

The accompanying `res86.doc` says the program was contributed to the CP/M user
group and asks users to use it to understand computers and customize software
they legitimately own. It does not include an explicit license granting
redistribution or modification rights. No separate license was supplied with
these files.

Consequently this port does not label the historical code public domain or
assign it a modern open-source license. This file records provenance and the
limits of the available evidence; it is not a replacement license grant.
