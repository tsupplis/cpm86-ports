# Historical licensing evidence

Tassell, based on Super Directory by Bruce R. Ratoff and DIRS by Keith Petersen.
Its comments mention SIG/M distribution; the executable banner identifies the
later D 4.8C2 variant. The supplied manual describes SD 4.8C.

No explicit redistribution or modification license was found in the supplied
source or manual. Attribution and historical user-group distribution are
preserved here; neither establishes a public-domain or modern open-source
license grant. This file records provenance, not a replacement license.
